# COUNT DOWN

> 조준을 유지해 카운트다운을 진행하고, 상대보다 먼저 발사하는 아레나 액션 게임입니다.

- **제작 목적:** GMTK Game Jam 2026 참가
- **플랫폼:** Unity / WebGL
- **플레이 영상:** https://youtu.be/RtzicIUArmw

---

## 게임 개요

**COUNT DOWN**은 이동과 조준을 동시에 관리하는 짧은 아레나 액션 게임입니다.

플레이어와 적은 조준을 유지하는 동안 각자의 카운트다운을 진행합니다. 숫자가 0에 도달하면 공격할 수 있으며, 조준을 해제하면 현재 방향으로 빠르게 이동합니다.

핵심은 단순합니다.

1. 적의 공격선을 피하며 이동합니다.
2. 조준을 유지해 카운트다운을 진행합니다.
3. 발사 시점과 회피 시점을 선택합니다.
4. 모든 적을 제거하면 다음 스테이지로 이동합니다.

---

## 주요 규칙

- 플레이어와 적의 체력은 각각 **3**입니다.
- 플레이어 카운트다운은 **3~7초** 범위입니다.
- 첫 스테이지의 적 카운트다운은 **10~15초** 범위입니다.
- 스테이지가 진행될수록 적의 카운트다운이 **3~7초**까지 짧아집니다.
- 첫 스테이지에는 적이 **2명** 등장합니다.
- 스테이지를 클리어할 때마다 적이 한 명씩 추가됩니다.
- 스테이지 클리어 시 플레이어 체력이 회복됩니다.
- 플레이어의 투사체는 적에게 3의 피해를 줍니다.
- 적 투사체와 근접 공격은 플레이어에게 1의 피해를 줍니다.

## 조작

### 데스크톱

| 입력                    | 동작               |
| ----------------------- | ------------------ |
| `WASD`                  | 이동               |
| 마우스                  | 방향 지정          |
| 마우스 오른쪽 버튼 유지 | 조준 및 카운트다운 |
| 마우스 오른쪽 버튼 해제 | 지정 방향으로 대시 |
| `R`                     | 재시작             |
| `Esc`                   | 종료               |

### 모바일

- 화면 왼쪽을 드래그해 이동합니다.
- 화면 오른쪽을 누르고 드래그해 방향을 지정하고 조준합니다.
- 터치 거리로 아날로그 입력 강도가 결정됩니다.
- 재시작 버튼을 눌러 게임을 다시 시작합니다.

### 게임패드

- 좌측 스틱으로 이동합니다.
- 우측 스틱으로 방향을 지정합니다.
- 조준 입력을 유지해 카운트다운을 진행합니다.

## 구현 특징

프로젝트는 Unity 씬에 다수의 오브젝트를 미리 배치하는 방식보다, 실행 시 필요한 요소를 구성하는 방식을 사용했습니다.

- `Main.unity` 실행 시 게임 월드를 런타임에 생성합니다.
- 필수 씬 연결 없이 게임을 시작할 수 있습니다.
- 그래픽 리소스가 없을 경우 기본 도형과 대체 리소스를 사용합니다.
- 지정된 `Resources/CountDown/` 경로에 파일을 추가해 그래픽을 교체할 수 있습니다.
- 조준 보조, 목표 고정, 적 회피, 공격 예고, 근접 공격을 포함합니다.
- WebGL 배포를 지원합니다.
- 10개 언어를 지원합니다.

지원 언어는 영어, 한국어, 일본어, 중국어 간체, 중국어 번체, 프랑스어, 독일어, 스페인어, 태국어, 포르투갈어입니다.

## 프로젝트 구성

주요 파일은 다음과 같습니다.

```text
Assets/
└─ Scripts/
   └─ CountDown/
      ├─ CountDownGame.cs
      └─ README.md

Assets/
└─ Resources/
   └─ CountDown/
      └─ Sprites/
         └─ SPRITE_GUIDE.md

ITCH_PAGE.md
DEPLOYMENT.md
```

### 주요 역할

- `CountDownGame.cs`  
  게임 규칙, 입력, 스테이지 진행, 적 동작, 공격 및 런타임 구성을 담당합니다.

- `Assets/Scripts/CountDown/README.md`  
  실행 방법, 조작법, 리소스 교체 방식을 설명합니다.

- `SPRITE_GUIDE.md`  
  교체 가능한 이미지 리소스의 규격과 경로를 설명합니다.

- `ITCH_PAGE.md`  
  게임 소개와 배포 페이지용 설명을 정리합니다.

- `DEPLOYMENT.md`  
  WebGL 빌드 및 배포 절차를 설명합니다.

## 정리

**COUNT DOWN**은 카운트다운을 공격 준비 시간으로 사용한 소규모 아레나 액션 게임입니다.

조준을 오래 유지할수록 공격에 가까워지지만 이동 속도가 제한되며, 조준을 해제하면 공격 기회를 포기하는 대신 빠르게 회피할 수 있습니다. 이 선택을 짧은 스테이지 안에서 반복하도록 구성했습니다.
